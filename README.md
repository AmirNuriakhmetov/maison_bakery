# Maison Miette — bakery website

Уютный адаптивный сайт-визитка пекарни в тёплой кремовой и терракотовой палитре.

## Запуск
Откройте `index.html` в браузере.

## Перед публикацией
Замените демонстрационные адрес, телефон, Telegram и цены на реальные данные. Фотографии загружаются с Unsplash, шрифты — с Google Fonts.

## Файлы
- `index.html` — структура и контент
- `style.css` — дизайн и адаптивная вёрстка
- `script.js` — мобильное меню и плавное появление блоков
